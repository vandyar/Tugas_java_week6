1. JavaScript (JS) adalah bahasa pemrograman tingkat tinggi, bersifat dinamis, dan berjalan di sisi klien (client-side scripting language). Bersama dengan HTML dan CSS, JavaScript merupakan pilar utama dalam membangun halaman web modern.
Kegunaan:
• Menambahkan interaktivitas pada website (seperti merespons klik tombol, animasi, atau validasi formulir secara real-time).
• Memanipulasi struktur dan gaya halaman web (HTML & CSS) secara dinamis tanpa perlu memuat ulang (reload) halaman.
• Mengembangkan aplikasi di luar web browser melalui lingkungan runtime seperti Node.js (untuk server/back-end).

2. jQuery adalah pustaka (library) open-source yang dibangun di atas JavaScript. jQuery diciptakan dengan slogan "Write less, do more" untuk menyederhanakan penulisan kode JavaScript standar yang sering kali panjang dan rumit.
Kegunaan:
• Mempermudah manipulasi elemen HTML (DOM) dengan sintaksis yang jauh lebih pendek dan intuitif.
• Menyederhanakan penanganan event (seperti klik atau gerakan mouse) dan pembuatan animasi web.
• Memudahkan pengelolaan fitur AJAX guna bertukar data dengan server secara asinkron tanpa memuat ulang halaman.
• Menjamin kompatibilitas kode di berbagai jenis browser web lama maupun baru secara otomatis.

Karakteristik	JavaScript	jQuery
Jenis Alat	Bahasa pemrograman dasar (core language).	Pustaka (library) yang dibuat menggunakan kode JavaScript.
Ketergantungan	Dapat berdiri sendiri tanpa bantuan pustaka eksternal.	Bergantung sepenuhnya pada JavaScript dan membutuhkan file script jQuery agar bisa berjalan.
Sintaksis	Cenderung lebih panjang dan kompleks untuk melakukan satu tugas sederhana.	Sangat ringkas, pendek, dan mudah dibaca oleh pemula.

Kompatibilitas Browser	Terkadang membutuhkan penyesuaian kode manual agar berjalan lancar di browser yang berbeda.	Menangani kompatibilitas lintas-browser secara otomatis di latar belakang.
